# 投資ノート（investment-app）

ユウタ専用・投資学習/管理アプリ。**iPhoneで使う・完全無料・データは端末内のみ**を満たす
PWA（Progressive Web App）として実装しています。仕様は本リポジトリのタスク依頼（設計書 v2）に基づきます。

- コア（インデックス積立）を主役に据え、サテライト（個別株の守り・攻め）を「加速装置」として管理
- ポジションには必ず投資ノート（Thesis）を紐づけ、決算後に答え合わせする規律を強制
- 億り人シミュレーターで「積立×複利」の力を可視化
- データはすべて **IndexedDB（端末内）** に保存。サーバーなし・課金なし

現時点では設計書の **Phase 1（MVP）** を実装済みです。Phase 2 以降の拡張ポイントは末尾に記載しています。

## スタック

| 項目 | 採用 |
|---|---|
| フレームワーク | Vite + React + TypeScript |
| PWA化 | vite-plugin-pwa（Workbox） |
| データ保存 | Dexie.js（IndexedDB） |
| UI | Tailwind CSS v4（モバイルファースト） |
| グラフ | Recharts（シミュレーター画面のみ遅延読み込み） |
| ルーティング | react-router-dom（HashRouter。静的ホスティングでリライト設定不要） |

サーバーサイドの実装はありません。ビルドすると静的ファイル一式（`dist/`）が生成されるだけです。

## ローカルで動かす

```bash
npm install
npm run dev       # http://localhost:5173 で開発サーバー起動
npm run build      # dist/ に本番ビルドを出力
npm run preview    # ビルド結果をローカルで確認
```

Node.js 20 以上を推奨します。

## 無料でデプロイする（Cloudflare Pages 例）

1. GitHub にこのリポジトリを push しておく
2. [Cloudflare Pages](https://pages.cloudflare.com/) で「Create a project」→ このリポジトリを接続
3. ビルド設定
   - Framework preset: `Vite`
   - Build command: `npm run build`
   - Build output directory: `dist`
   - Root directory: `investment-app`（このアプリがリポジトリのサブディレクトリにあるため）
4. デプロイすると `https://xxxx.pages.dev` のようなURLが発行されます

Vercel / Netlify でも同様に「Root Directory を `investment-app` にする」「Build command: `npm run build`」
「Output: `dist`」を指定すれば無料枠でデプロイできます。GitHub Pages を使う場合は `dist` の内容を
`gh-pages` ブランチなどに配置してください（HashRouterを採用しているため、静的ホスティングであれば
リライト設定は不要です）。

## iPhoneでホーム画面に追加する

1. デプロイしたURLを **Safari** で開く（Chromeなど他ブラウザではPWAとして追加できません）
2. 画面下部の「共有」ボタン（□に↑のアイコン）をタップ
3. 「ホーム画面に追加」を選択 → 右上の「追加」をタップ

ホーム画面のアイコンから起動すると、Safariのアドレスバーなどが無い全画面表示（standalone）で
ネイティブアプリのように使えます。オフラインでも一度読み込んだ後は動作します。

## データの扱い（重要）

- すべてのデータ（口座・保有銘柄・投資ノート・取引記録など）は **この端末のIndexedDBにのみ** 保存されます。
  サーバーへの送信は一切ありません。
- リポジトリにも実データ（保有銘柄名や金額など）は含めていません。初回起動後、アプリ内で入力してください。
- iOSはSafari/PWAのIndexedDBを、長期間未使用の場合などに削除することがあります。対策として、
  - 起動時に `navigator.storage.persist()` で永続化をリクエストしています
  - 設定タブから **JSONエクスポート** ができます。週1回を目安に、iCloud Driveなど端末外にも
    バックアップを保存することを強く推奨します（アプリ内にもリマインダーを表示します）
  - 同じ設定タブから **JSONインポート** でいつでも復元できます

## 実装にあたって置いた仮定

- **通貨は円建て統一**（設計書の推奨どおり）。米国株も証券アプリの円換算表示をそのまま入力する想定で、
  為替レートの管理は行いません（Phase 4 での拡張候補）。
- **株価は手入力**。無料で安定した価格APIが乏しいため、ポートフォリオ画面の「価格更新」から
  週1回〜決算時にまとめて更新する運用を前提にしています。
- 投資ノート（Thesis）は保有銘柄1件につき複数作成できますが、UI上は最新の1件を「現在のノート」として
  銘柄詳細に表示します（買い直し・仕切り直しのたびに新しいノートを作る運用を想定）。
- 決算カレンダーの自動生成・通知は実装していません（Phase 2）。代わりに、レビューが1件も無い
  運用中ノートを「決算レビュー待ち」として投資ノートタブに表示し、決算後に振り返る導線としています。
- 「1銘柄あたりの上限比率」は総資産（評価額ベース）に対する比率で判定し、超過時はポートフォリオ画面に
  警告バッジを出します（発注のブロックなどは行いません）。
- PWAの新バージョン検知は `registerType: 'prompt'` を採用しています。`autoUpdate` にすると
  新しいService Workerが有効化された瞬間に自動でページがリロードされ、フォーム入力中のデータが
  消えてしまう恐れがあるため、あえてユーザーが「更新する」を押した時だけ更新する設計にしています。

## 画面構成

下タブ5つ：ホーム（ダッシュボード）／ポート（ポートフォリオ）／ノート（投資ノート）／学ぶ／設定。

- **ホーム**：純資産評価額、コア:サテライト比率、守り:攻め比率、億り人ゲージ、ノート未記入警告
- **ポート**：口座別・銘柄別の保有一覧、銘柄追加・編集、価格の一括更新、取引記録
- **ノート**：投資ノート（Thesis）一覧、決算レビューの記録、未記入銘柄への導線
- **学ぶ**：採用シグナル・ボード（ユウタ固有のエッジ：IT×人材の一次情報を投資アイデアの種として記録）
- **設定**：口座管理、1銘柄あたりの上限比率、表示テーマ、バックアップ（エクスポート/インポート）、
  ホーム画面追加ガイド

シミュレーター（億り人シミュレーター）はホームまたは設定からアクセスします。

## Phase 2 以降への拡張ポイント（未実装）

コードは機能ごとに `src/pages/`・`src/lib/`・`src/db/db.ts` に分割してあり、以下は
既存のデータモデル（`src/db/db.ts` の `candidates` / `scorecards` / `lessons` /
`learningProgress` テーブルなど）を土台に追加しやすい構成にしています。

- **Phase 2**：スコアカード（守り/攻めの指標入力・総合スコア）、ウォッチリスト（候補銘柄の監視・見送り・
  購入検討の仕分け）、決算カレンダー＋自動レビュータスク生成、税・複利トラッキングの精緻化
- **Phase 3**：AIチューター機能。API課金を避けるため、アプリが最適なプロンプト文字列を生成して
  「コピー」→ ユーザーが自分のClaudeアプリに貼る方式を想定（指標解説・ノート添削・決算サマリー・クイズ）
- **Phase 4**：為替（JPY/USD）を考慮した円建て統合評価、証券会社CSVの取り込み、配当年間カレンダー、
  自分のAPIキーを使ったAI機能の完全自動化オプション

## ディレクトリ構成

```
src/
  db/            Dexie（IndexedDB）のスキーマ定義
  lib/           集計・複利計算・フォーマット・エクスポート/インポート・テーマ切り替えなどのロジック
  hooks/         Dexieのライブクエリをラップしたカスタムフック
  components/    共通UIコンポーネント（レイアウト・フォーム部品・アイコンなど）
  pages/         画面ごとのコンポーネント（react-router-domのルートに対応）
```
